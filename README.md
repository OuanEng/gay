# House / Reset

เกมทำความสะอาดคฤหาสน์แบบ low-poly สร้างด้วย Godot 4

เล่นบนเว็บ: https://ouaneng.github.io/gay/

มี 5 ห้อง: โถงต้อนรับ ห้องนอน ห้องอาหาร ห้องสมุด และห้องบอลรูม
แต่ละห้องต้องเก็บโฟม ถูพื้น/เช็ดคราบ และจัดของให้ครบ จึงรับเงินและแต้มสกิลได้

เงินใช้ซื้อถุงมือ ไม้ถู รองเท้าทำงาน แม่เหล็กจัดของ เครื่องเป่า เครื่องดูดโฟม และผู้ช่วยอัตโนมัติที่หน้าสรุปหลังจบแต่ละห้อง

- WASD: เดิน / เมาส์: มอง
- คลิกค้าง: เก็บโฟมหรือถูคราบ / E: ใช้งาน
- 1–3: เลือกอุปกรณ์ / K: สกิล / ESC: หยุดเกม
- F10: เมนูทดสอบ เพิ่มเงิน แต้มสกิล และเลือกห้อง

เว็บสำหรับ GitHub Pages อยู่ใน `docs/`
