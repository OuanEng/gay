# House / Reset

เกมทำความสะอาดคฤหาสน์แบบ low-poly สร้างด้วย Godot 4

เล่นบนเว็บ: https://ouaneng.github.io/gay/

มี 5 ห้อง: โถงต้อนรับ ห้องนอน ห้องอาหาร ห้องสมุด และห้องบอลรูม
แต่ละห้องต้องดูดโฟม ถูพื้น/เช็ดคราบ และจัดของให้ครบ จึงรับเงินและแต้มสกิลได้

เริ่มต้นด้วยมือ เครื่องดูดโฟม และไม้ถู เครื่องดูดมีระยะและความจุ เมื่อเต็มต้องกลับไปทิ้งที่ถังสีส้ม ไม้ถูสะสมคราบและต้องล้างที่อ่างสีฟ้า เงินใช้เพิ่มความจุ ระยะดูด ความเร็วการถู ความเร็วเดิน มือที่สอง และซื้อหรืออัปเกรดหุ่นผู้ช่วย
เมื่อเครื่องดูดเต็มหรือไม้ถูสกปรก ไอคอนบนแถบอุปกรณ์จะเปลี่ยนสี พร้อมสัญลักษณ์เตือนใกล้จุดเล็งและสีของอุปกรณ์ที่ถืออยู่

งานทำความสะอาดเพิ่มเป็น 5, 9, 14, 20 และ 28 จุดตามลำดับห้อง ส่วนงานจัดของเพิ่มเป็น 3, 5, 8, 12 และ 17 ชิ้น Skill Tree มี 5 สาย สายละ 3 ขั้น และต้องปลดจากล่างขึ้นบน

- WASD: เดิน / เมาส์: มอง
- คลิกค้าง: ดูดโฟมหรือถูคราบ / คลิก: จัดของ / E: ทิ้งโฟมหรือล้างไม้ถูที่จุดบริการ
- 1–3: เลือกอุปกรณ์ / K: สกิล / ESC: หยุดเกม
- F10: เมนูทดสอบ เพิ่มเงิน แต้มสกิล และเลือกห้อง
